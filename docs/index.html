burnie

Some agents just want to watch your tokens burn.

A local cost analytics tool for Claude Code. It tells you not just how much your sessions cost, but which ones were abnormally expensive, and why.

uvx burnie
View on GitHub

What it does

  • Report: a visual HTML breakdown of token costs, total spend, daily average, cache savings, cost by model and by project.
  • Inspect: drill into any session to see what drove the cost, and how it compares to similar sessions.
  • Analyze: the /burnie skill runs the report through Claude for a written take on what's actually worth changing.
  • Statusline: the active session's running cost live in Claude Code's terminal UI, escalating 🔥 as it gets pricey.

Install

# run without installing uvx burnie # get the /burnie skill into Claude Code burnie --install-skill # live cost counter in your terminal status line burnie --install-statusline

Cost & privacy

The dollar figures are API-equivalent costs from Anthropic's published rates, not necessarily what a Pro or Max plan bills you. Good for comparing sessions, not an invoice.

Everything runs on your machine. No API key, no account access, no data leaves your computer.
